## 改动范围

- `intel-hidpi.sh` 的 inventory 输入先经过离线捕获边界检查，拒绝符号链接、非普通文件、NUL 内容和超限输入。
- inventory 的 override 根和目标 override 拒绝符号链接；目标文件通过安全文件快照和描述符绑定的 plist 读取，缺少 `scale-resolutions` 仍报告 `none`，其他读取变化显式失败。
- smooth 模式在使用 `smooth_mode_count - 1` 前增加数量下界断言，避免未来修改几何约束时出现除零路径。
- `lib/intel_hidpi_plist_arrays.sh` 通过 FD 3 向 Ruby 传递生成 payload，标准输入继续承载 plist XML，避免完整 payload 出现在命令行参数中。
