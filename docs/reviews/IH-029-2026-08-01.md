## 发现与处置

1. `intel-hidpi.sh` 的 `payload_dimensions` 使用 `xxd -p -c 100`。解码后的数据超过 100 字节时，
   `xxd` 会插入换行，而十六进制校验未移除换行，合法长 payload 会被误判为无效。该问题可触发，
   已拆分为 IH-030。
2. `lib/intel_hidpi_similar_resolutions.sh` 的重复 payload 和空输入线索不构成当前公开路径缺陷：
   helper 只由 smooth 模式且有预览输出时调用，空输入不会从公开命令进入。保留现有 fail-closed
   行为，不为不可达路径增加误导性日志。
3. IH-028 的英文残留扫描说明没有记录足够的可复现命令和退出码，已拆分为 IH-031。
4. `CR-EXTERNAL` 依赖 `/private/tmp` 下的 OMP 原始 JSONL。该文件当前存在并有 SHA-256，但临时
   路径不应作为唯一长期证据，已拆分为 IH-031。
