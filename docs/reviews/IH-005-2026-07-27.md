# IH-005 验证记录

## 范围

本记录收口已获授权的 Lenovo `30ae:62a5` 回退验证，只记录精确回退及其非侵入式后置条件。
不声称新的 HiDPI 模式已经激活，也不声称在系统生命周期事件后验证了显示器行为。

永久操作边界如下：

- 不得重启系统；
- 不得为本任务睡眠、唤醒、热插拔或重新连接显示器；
- 不得重载显示服务或以其他方式重初始化显示子系统；
- 不得再次执行真实 `apply` 或 `revert`；
- 本任务只涉及 Lenovo 目标 `30ae:62a5`，4K 显示器 `10ac:41fe` 仅用于观察。

## 已执行的授权操作

本次验收唯一执行的真实回退命令为：

```sh
sudo /Volumes/Work/code/one-key-hidpi/intel-hidpi.sh revert \
  --vendor-id 30ae --product-id 62a5 --migrate-v4 --confirm
```

命令报告：

```text
reverted=DisplayVendorID-30ae/DisplayProductID-62a5
```

本仓库不记录密码。

## 只读后置条件

回退后执行了以下只读命令：

```sh
shasum -a 256 \
  /Library/Displays/Contents/Resources/Overrides/DisplayVendorID-30ae/DisplayProductID-62a5 \
  /Library/Displays/Contents/Resources/Overrides/DisplayVendorID-10ac/DisplayProductID-41fe
plutil -lint \
  /Library/Displays/Contents/Resources/Overrides/DisplayVendorID-30ae/DisplayProductID-62a5
find '/Library/Application Support/one-key-hidpi/DisplayVendorID-30ae/DisplayProductID-62a5' \
  -maxdepth 1 \( -name original.plist -o -name manifest.plist -o -name '*.lock' \) -print
```

观察结果：

- Lenovo `30ae:62a5` 的 SHA-256 为
  `f6453074f21de04b54ca37d25dd248473a0e3240f63bb7b810c8d808d5fc2aad`，与 apply 前原始值相同；
- 临时应用版本的 Lenovo SHA-256 曾为
  `8b4ec4aac5e6d10afd1951561bd392631e39e19fc772ca98267283989995e00f`；
- 4K `10ac:41fe` 的 SHA-256 仍为
  `7e2ffd4f7d3f4655a6aebb555eb38bcdc18e3ea3d8a8ce9ba62482ea8414e42b`；
- `plutil -lint` 对 Lenovo plist 报告 `OK`；
- Lenovo 单显示器状态目录存在但为空，没有 `original.plist`、`manifest.plist` 或目标锁；全局
  `.one-key-hidpi-locks` 目录也存在但为空；
- 进程检查没有发现残留的 Intel HiDPI 测试或操作进程。

## 自动回归边界

所有后续检查只使用 `mktemp` fixture 目录下的自定义根。不得使用默认
`/Library/Displays` 或 `/Library/Application Support/one-key-hidpi` 路径进行写入。静态复核也
没有发现生产命令调用重启、`pmset`、`killall`、`launchctl` 或显示服务重载。

## 明确未验证项

以下结果在永久禁止重载的规则下有意保持未验证：

- 重启后 HiDPI 模式是否可见；
- 睡眠/唤醒行为；
- 热插拔或重新插接线缆行为；
- 显示服务器重载或重初始化行为。

已验证结果仅限于 Lenovo 精确回退、没有残留工具状态，以及未观察到 4K 显示器 override 发生变化。

## 历史模式枚举限制

较早的重启后 CoreGraphics 检查使用了 `CGMainDisplayID()`，没有按 vendor 和 product ID 解析
Lenovo。在多显示器布局中主显示器可能变化，因此该枚举不能证明列出的模式属于 `30ae:62a5`，
不得把它当作 Lenovo 激活结果。

IH-017 增加了按目标绑定的只读 `verify-modes` 命令，会同时比较所请求显示器的逻辑尺寸和
framebuffer 尺寸。没有使用后续真实 apply、显示服务重载或模式激活来替代这项历史观察。
