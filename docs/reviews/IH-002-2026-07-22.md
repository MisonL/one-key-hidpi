# IH-002 验证记录

## 范围

在 `intel-hidpi.sh` 中实现只读的 Intel HiDPI 模式预览生成器。命令根据面板分辨率计算固定
候选模式，并输出对应的 16 字节 HiDPI payload。它不会写入 EDID override，也不会调用 `sudo`。

## 命令

```sh
bash tests/test_intel_hidpi_inventory.sh
bash tests/test_intel_hidpi_preview.sh
bash -n intel-hidpi.sh
shellcheck -s bash intel-hidpi.sh tests/test_intel_hidpi_inventory.sh tests/test_intel_hidpi_preview.sh
git diff --check
./intel-hidpi.sh preview --native-resolution 3840x2160
```

## 结果

所有命令均以退出码 0 完成。fixture 测试覆盖：

- 3840x2160 模式生成和精确的 16 字节 payload 编码；
- 3440x1440 向偶数尺寸取整；
- 4x4 fixture 的去重；
- 非法输入拒绝；
- framebuffer 超限时拒绝且标准输出不产生部分结果；
- 生成的 16 字节 payload 与旧脚本 `create_res_2` 编码形式等价。

连接中的 3840x2160 显示器只读预览生成了从 1920x1080 到 3840x2160 的五个候选逻辑模式。
本次验证没有写入系统 override。
