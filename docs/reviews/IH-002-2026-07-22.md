# IH-002 Verification Record

## Scope

Implemented a read-only Intel HiDPI mode preview generator in
`intel-hidpi.sh`. The command calculates fixed candidate modes from a panel
resolution and emits the matching 16-byte HiDPI payload. It does not write an
EDID override or invoke `sudo`.

## Commands

```sh
bash tests/test_intel_hidpi_inventory.sh
bash tests/test_intel_hidpi_preview.sh
bash -n intel-hidpi.sh
shellcheck -s bash intel-hidpi.sh tests/test_intel_hidpi_inventory.sh tests/test_intel_hidpi_preview.sh
git diff --check
./intel-hidpi.sh preview --native-resolution 3840x2160
```

## Result

All commands exited with code 0. The fixture tests cover the following:

- 3840x2160 mode generation and exact 16-byte payload encoding.
- 3440x1440 rounding to even dimensions.
- Deduplication for a 4x4 fixture.
- Invalid input rejection.
- Framebuffer limit rejection without partial standard-output results.
- Equivalence of the generated 16-byte payload with the legacy script's
  `create_res_2` encoding form.

The live read-only preview on the connected 3840x2160 display produced five
candidate logical modes from 1920x1080 through 3840x2160. No system override
was written during this verification.
