## 结论和边界

本地 smooth + near-native + similar 生成逻辑与远程 BetterDisplay 已保存的两份 override payload 集合逐项一致，两个目标的本地 `verify-override` 均为 exact。普通 payload 的语义是每个候选的逻辑尺寸和 2x framebuffer 尺寸；HiDPI payload 的语义是对应 2x framebuffer。

这证明了 override 配置兼容性，不证明 macOS 在真实 apply 后一定接受并暴露全部运行时模式。当前远程主机使用 AMD GPU、BetterDisplay 进程未运行且只有一个目标在线；按照永久约束，本轮没有执行真实 apply、revert、显示服务重载、重启、睡眠、唤醒或热插拔，也没有使用 sudo。
