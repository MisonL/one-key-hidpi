# IH-014 验证记录

## 范围

收口系统 Overrides 树与 HiDPI 回退状态之间的信任边界：

- `storage_roots_have_matching_trust` 使用既有默认根和 Data 卷别名，将规范化根分类为系统根或
  自定义根；
- apply 和 revert 在根规范化后立即调用该门禁，早于派生目标路径、状态目录、锁路径、manifest
  路径或创建任何目录；
- 系统 Overrides 根现在必须配套系统 state 根，系统 state 根也必须配套系统 Overrides 根；
  自定义/自定义 fixture 根仍受支持。

## 安全边界

此前特权调用可以将系统 Overrides 根与任意自定义 state 根组合。该自定义根中的伪造 manifest 和
备份可能在 revert 时被当作有效状态。新门禁在读取 manifest 或创建状态目录前拒绝两种混用组合。

`test_intel_hidpi_root_binding.sh` 在规范化后验证四种根组合：系统/系统、自定义/自定义、
系统/自定义和自定义/系统。允许的自定义/自定义组合执行真实的自定义 apply/revert 循环；两个
混用组合均断言显式错误和自定义 fixture 目录不存在，证明拒绝发生在任何状态写入之前。系统
路径参数只用于拒绝测试，所有写入 fixture 均位于 `mktemp` 下。

## 自审

- apply 和 revert 都在派生目标或状态路径前调用门禁，回退路径无法绕过；
- 词法规范化后仍能识别既有系统根别名；
- 本任务没有使用显示器 override、系统 state、`sudo` 或真实显示器配置。
