# IH-014 Verification Record

## Scope

Close the trust-boundary gap between the system Overrides tree and HiDPI
recovery state.

- `storage_roots_have_matching_trust` classifies normalized roots as system or
  custom using the existing default-root and Data-volume aliases.
- Apply and revert call this gate immediately after root normalization and
  before deriving a target path, state directory, lock path, manifest path, or
  creating any directory.
- A system Overrides root now requires a system state root. A system state root
  now requires a system Overrides root. Custom/custom fixture roots remain
  supported.

## Security Boundary

Previously a privileged invocation could combine the system Overrides root
with an arbitrary custom state root. A valid-looking manifest and backup in
that custom root could then be considered during a revert. The new gate rejects
both mixed combinations before reading a manifest or creating a state
directory.
