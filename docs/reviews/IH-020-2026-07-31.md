## 实现核对

- preview、apply、verify-modes、verify-override 和交互菜单均贯通 --include-similar-resolutions。
- smooth + near-native + similar 对 1920x1080 生成 42 个 16-byte HiDPI payload、84 个去重的 8-byte 普通 payload，总计 126 个。
- 普通 payload 分别对应每个候选的逻辑尺寸和 2x framebuffer 尺寸，普通记录的逻辑尺寸与 framebuffer 尺寸相同。
- manifest 记录 mode-set、include-near-native 和 include-similar-resolutions；回退仍由 v5 manifest、哈希和持久身份保护。
- plist 读取和合并使用 REXML 结构化处理。核验只统计 scale-resolutions 数组的直接 data 子项；既有非 data 项和嵌套 data 保留但不计入 payload 集合。
- 空 direct data、畸形 Base64、缺失 scale-resolutions 和目标标识不匹配均显式失败或返回不匹配，不静默生成成功结论。
