# IH-007 验证记录

## 范围

加固 `intel-hidpi.sh` 中只读 Intel 显示器盘点的边界。

- EDID 输入必须包含完整的 128 字节块，使用标准头，并通过基础块校验和；
- 显示器名称只从四个正式的基础块描述符读取，并在输出前限制为可打印 ASCII；
- 盘点使用与 apply 和 revert 相同的辅助函数规范化 vendor 和 product ID，路径不会保留前导零；
- 已有 override 损坏时报告为无效，不尝试提取模式。

fixture EDID 已修正为有效的 128 字节基础块，同时保留之前的显示器身份、名称和首选分辨率。

## 自动验证

以下命令均以退出码 0 完成：

```sh
bash tests/test_intel_hidpi_inventory.sh
bash -n intel-hidpi.sh tests/test_intel_hidpi_inventory.sh
shellcheck -s bash -x -P "$PWD" intel-hidpi.sh \
  lib/intel_hidpi_storage.sh tests/test_intel_hidpi_inventory.sh
git diff --check
```

盘点回归覆盖：

- 有效的多显示器盘点和原生分辨率解析；
- 不完整、头无效、长度为奇数和校验和无效的 EDID；
- 含转义字节的显示器名称描述符；
- 前导零 vendor/product ID 映射到与 apply 和 revert 相同的 override 名称；
- 将损坏的既有 plist 报告为 `invalid`，并将模式数据标记为不可用。

本任务没有向 `/Library/Displays` 或 `/Library/Application Support` 写入任何内容。
