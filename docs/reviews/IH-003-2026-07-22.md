# IH-003 Verification Record

## Scope

Implemented confirmed `apply` and `revert` operations for one selected Intel
display override. Storage behavior is isolated in `lib/intel_hidpi_storage.sh`
so the command entry point remains focused on parsing and read-only display
inspection.

`apply` creates same-directory candidate files, retains unrelated target plist
metadata, records an exact original backup when applicable, writes a versioned
manifest, and atomically moves only the selected product override. `revert`
checks the manifest identity and hashes before restoring or deleting that exact
target file.

The default system paths require an explicit root invocation. The command does
not invoke `sudo` itself. Written target, backup, manifest, and restore-candidate
files are mode `0644`; writes to default system paths also set `root:wheel`
ownership.

## Result

All commands exited with code 0. The apply/revert fixture covers:

- Merging modes while retaining target metadata, EDID data, and an existing payload.
- Preserving a separate product override in the same vendor directory.
- Exact backup and restore of an existing target plist.
- Creation and later removal of an absent target plist only.
- Creation and exact restoration of an existing plist without `scale-resolutions`.
- `0644` permissions for generated target and manifest files in the fixture root.
- Manifest version, target identity, payload list, original hash, candidate hash, and native resolution.
- Explicit rejection without `--confirm`, rejection of invalid generated modes without target writes, and rejection of a target modified after apply.

No command in this task wrote to `/Library/Displays` or `/Library/Application Support`.
The command entry point was reviewed after extracting all write and rollback
behavior into a dedicated storage module; it retains only command dispatch,
read-only inventory, and mode preview responsibilities.
Hardware activation, reboot behavior, sleep/wake, cable replug, and a root-owned
system-path acceptance test remain IH-004 work.
