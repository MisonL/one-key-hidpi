# IH-003 验证记录

## 范围

为一个选定的 Intel 显示器 override 实现已确认的 `apply` 和 `revert` 操作。存储行为隔离在
`lib/intel_hidpi_storage.sh` 中，使命令入口可以专注于参数解析和只读显示器检查。

`apply` 在同一目录创建候选文件，保留目标 plist 的无关元数据，在适用时记录精确的原始备份，
写入带版本的 manifest，并且只原子移动选定的产品 override。`revert` 会核验 manifest 身份和
哈希，然后恢复或删除该精确目标文件。

默认系统路径要求显式以 root 身份调用。命令本身不会调用 `sudo`。写入的目标、备份、manifest
和恢复候选文件权限均为 `0644`；写入默认系统路径时还会设置 `root:wheel` 所有者。

## 命令

```sh
bash tests/test_intel_hidpi_inventory.sh
bash tests/test_intel_hidpi_preview.sh
bash tests/test_intel_hidpi_apply_revert.sh
bash -n intel-hidpi.sh

bash -n tests/test_intel_hidpi_inventory.sh
bash -n tests/test_intel_hidpi_preview.sh
bash -n tests/test_intel_hidpi_apply_revert.sh
shellcheck -s bash intel-hidpi.sh lib/intel_hidpi_storage.sh tests/test_intel_hidpi_inventory.sh tests/test_intel_hidpi_preview.sh tests/test_intel_hidpi_apply_revert.sh
git diff --check
(cd /tmp && /Volumes/Work/code/one-key-hidpi/intel-hidpi.sh preview --native-resolution 3840x2160)
```

## 结果

所有命令均以退出码 0 完成。apply/revert fixture 覆盖：

- 合并模式时保留目标元数据、EDID 数据和既有 payload；
- 保留同一 vendor 目录下另一个产品的 override；
- 对既有目标 plist 精确备份并恢复；
- 只创建并随后移除缺失的目标 plist；
- 创建并精确恢复一个没有 `scale-resolutions` 的既有 plist；
- fixture 根目录中生成的目标和 manifest 文件均为 `0644`；
- manifest 版本、目标身份、payload 列表、原始哈希、候选哈希和原生分辨率；
- 没有 `--confirm` 时显式拒绝、生成模式非法时拒绝且不写目标，以及 apply 后目标被修改时拒绝。

本任务没有向 `/Library/Displays` 或 `/Library/Application Support` 写入任何内容。将所有写入和
回退行为提取到独立存储模块后重新检查了命令入口；入口只保留命令分派、只读盘点和模式预览。

硬件激活、重启、睡眠/唤醒、重新插拔线缆以及 root 所有系统路径的接受测试仍属于 IH-004 工作。
