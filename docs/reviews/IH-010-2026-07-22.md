# IH-010 验证记录

## 范围

在后续复核发现早期单显示器修复只有主 override plist 仍存在时才会删除图标附件后，完成旧版
按产品回退边界。

旧菜单和生成的 `.hidpi-disable` 辅助脚本现在都会在三个精确产品工件中任意一个存在时执行
检查，并且只删除以下当前产品工件：

- `DisplayProductID-<id>`；
- `DisplayProductID-<id>.icns`；
- `DisplayProductID-<id>.tiff`。

该条件也会识别悬挂符号链接，因此可以删除链接本身。删除命令仍是当前产品三个路径的固定
列表，不会遍历 vendor 目录。

## 自动验证

以下命令均以退出码 0 完成：

```sh
bash tests/test_intel_hidpi_menu.sh
bash -n hidpi.sh tests/test_intel_hidpi_menu.sh
shellcheck -s bash tests/test_intel_hidpi_menu.sh
git diff --check
```

菜单 fixture 验证旧版直接禁用和生成的恢复辅助脚本对以下情况的处理：

- 正常存在的选定 plist 和附件；
- plist 缺失但选定 `.icns` 和 `.tiff` 孤立存在；
- 选定附件为符号链接时只删除链接，外部目标保持不变；
- 同一 vendor 目录下 sibling 产品的文件和附件保留。

本任务没有向 `/Library/Displays` 或 `/Library/Application Support` 写入任何内容。
