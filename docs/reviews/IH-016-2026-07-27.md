# IH-016 验证记录

## 范围

本任务加强重启后或同内容文件替换后的回退授权，只修改 Intel 安全 apply/revert 实现。所有
自动写入均限制在 `mktemp` fixture 根目录。

本任务没有重启主机、睡眠或唤醒、热插拔显示器、重载显示服务，也没有写入真实显示器 override。

## 已实现边界

- manifest 版本 5 记录当前 boot session，并以 `inode:birthtime-seconds:birthtime-nanoseconds`
  形式记录候选文件及适用时原始备份的持久文件身份；
- apply 记录原始 override 的哈希、device/inode 和持久身份。安全复制、安装、替换、恢复和删除
  辅助函数在写入或清理边界（包括最终 manifest 清理）保留身份检查；
- 重启后只有哈希和持久身份仍匹配时才允许 device number 变化；同一 boot session 还要求记录的
  device/inode 身份匹配；
- v4 manifest 绝不会静默采用较弱的身份规则。回退必须传入 `--migrate-v4`，先核验旧版目标和
  备份，再原子写入已核验的 v5 manifest，并且只从迁移后的状态继续；
- v5 目标即使字节相同但持久身份不同，也会保留，不会被覆盖。

## 剩余边界

持久身份可以缩小意外或无特权的同内容替换竞态，但不能让回退事务免受拥有等价权限、可修改受保护
系统 override 树和 root 所有 state 树的攻击者影响。该进程仍可竞争独立文件系统调用；实现会
fail-closed，并在检查失败时保留状态。

## 复杂度豁免

尽管 `commit_apply_state` 和 `revert_override` 较长且位置参数较多，仍保持为内聚的事务边界。
拆分状态会增加可变安全上下文，使锁、临时文件和失败保留顺序更难审计。其阶段边界由专用
fixture 套件覆盖，本记录为 IH-016 记录该例外。
