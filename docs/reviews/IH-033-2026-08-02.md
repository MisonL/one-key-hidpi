# IH-033 验证记录

## 范围

本任务收口离线 ioreg、离线 modes 文件和显示器 override 中
`scale-resolutions` 的读取边界。所有写入只发生在测试创建的隔离临时目录；本轮没有使用
`sudo`，没有执行真实显示器 `apply` 或 `revert`，没有写入系统 Overrides，没有重载显示
服务，也没有重启、睡眠、唤醒或热插拔显示器。

## 实现收口

- `lib/intel_hidpi_darwin_fs.sh` 将离线文件读取绑定到父目录文件描述符，路径组件使用
  `openat` 和 `O_NOFOLLOW`；最终文件通过已打开的描述符读取，不按路径重新打开。
- 离线文件读取区分打开失败、符号链接、非普通文件或多链接文件、读取失败、NUL 内容和
  大小超限。非普通文件或多链接文件使用独立状态，符号链接仍保留原有诊断。
- plist 读取同时限制源文件大小 `1048576` 字节和转换输出大小。`scale-resolutions`
  数组 XML 的输出上限为 `131072` 字节，源 plist 超限与 XML 输出超限使用不同状态和诊断。
- `plist-key-type` 使用有界 XML 流和安全字段解析；字段缺失返回空数组语义，类型错误、
  语义解析失败和文件身份校验失败不会静默降级。
- 有界 `plutil` 读取以块为单位消费标准输出和标准错误。超限或异常时先发送 `TERM`，
  一秒内未退出则发送 `KILL`，随后关闭标准输入、标准输出和标准错误描述符，避免无限等待
  或无界积累错误输出。
- inventory、verify-modes 测试新增源 plist 超限和目录输入回归；已有符号链接、NUL、
  长 payload、缺失字段和错误类型覆盖保持有效。

## 复杂度记录

的 800 行强制审查阈值。前者仍是单一 Intel CLI 入口，后者集中承载 Darwin FFI、描述符
身份校验和原子存储操作；本任务只增加与离线读取直接相关的辅助操作。此时拆分会扩大
