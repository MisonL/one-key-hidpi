## 实现核对

1. `resolution_payload` 在编码前拒绝非正整数、前导零和超过 `4294967295` 的宽高，并返回稳定的 stderr 错误。
2. payload 编码 pipeline 在局部子 shell 中启用 `pipefail`，上游工具失败不会被最后一个过滤命令掩盖，也不会改变调用方的全局 shell 选项。
3. 相似分辨率生成先计算并比较同一迭代的 logical/framebuffer payload；相等时立即失败，统一输出数组尚未开始，因此不会泄漏重复模式行。
4. 既有 payload 去重、默认 smooth 模式和 BetterDisplay 取证集合保持不变。
