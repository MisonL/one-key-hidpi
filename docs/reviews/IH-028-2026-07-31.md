### 叙述性中文扫描

扫描范围由 `git ls-files -- '*.md'` 固定为仓库内已跟踪的全部 Markdown 文件，不读取 `.git` 或
未跟踪文件。以下命令逐文件处理 Markdown 围栏：围栏和缩进代码、标题、表格、HTML 注释、
行内代码、URL 和 Markdown 链接目标先排除；只报告不含中文且仍有至少两个常见英文连接词的
普通正文行。这样会排除命令、路径、标识符、URL、代码块和兼容性索引，并把疑似英文叙述输出
为非零结果：

```sh
/usr/bin/perl -e '
use open qw(:std :encoding(UTF-8));
open my $git, "-|", "/usr/bin/git", "ls-files", "-z", "--", "*.md"
    or die "无法启动 git ls-files: $!\n";
local $/ = "\0";
my @files = <$git>;
close $git or die "git ls-files 失败: $?\n";
chomp @files;
my $bad = 0;
for my $file (@files) {
    open my $fh, "<", $file or die "$file: $!\n";
    binmode $fh, ":encoding(UTF-8)";
    my $fence = 0;
    my $comment = 0;
    my $line_no = 0;
    while (my $line = <$fh>) {
        ++$line_no;
        chomp $line;
        if ($line =~ /^\s*(```|~~~)/) { $fence = !$fence; next; }
        next if $fence;
        next if $line =~ /^\s{4}/;
        next if $line =~ /^\s*(?:#{1,6}\s*|\|)/;
        if ($comment) {
            if ($line =~ s/.*?-->//) { $comment = 0; }
            else { next; }
        }
        if ($line =~ /<!--/) {
            if ($line =~ s/<!--.*?-->//g) {}
            else { $line =~ s/<!--.*\z//; $comment = 1; }
        }
        $line =~ s/`[^`]*`/ /g;
        $line =~ s{https?://\S+}{ }g;
        $line =~ s{\[[^\]]*\]\([^)]*\)}{ }g;
        next if $line =~ /[\x{4e00}-\x{9fff}]/;
        my @words = ($line =~ /\b(?:a|an|and|are|as|at|be|been|but|by|can|could|does|for|from|has|have|if|in|into|is|it|its|may|must|no|not|of|on|or|our|should|that|the|their|then|there|these|this|to|under|use|using|was|were|when|where|which|while|with|without|would)\b/gi);
        next unless @words >= 2;
        print "$file:$line_no:$line\n";
        $bad = 1;
    }
}
exit($bad ? 1 : 0);
'
```

本轮该命令退出码为 `0`，没有发现英文标题或英文叙述段落。它不是语言学证明：含中文的
混合行不会被报告，技术标识也可能出现在扫描结果中，最终判断仍需结合文件上下文。

### Markdown 围栏和本地链接检查

以下只读命令检查每个已跟踪 Markdown 文件的围栏是否成对，并解析相对链接；HTTP(S) URL、
锚点和链接标题不作为本地文件检查目标。任一未闭合围栏或缺失目标都会返回非零：

```sh
/usr/bin/perl -MFile::Basename=dirname -MFile::Spec -e '
open my $git, "-|", "/usr/bin/git", "ls-files", "-z", "--", "*.md"
    or die "无法启动 git ls-files: $!\n";
local $/ = "\0";
my @files = <$git>;
close $git or die "git ls-files 失败: $?\n";
chomp @files;
my $bad = 0;
for my $file (@files) {
    open my $fh, "<", $file or die "$file: $!\n";
    my $fence = 0;
    my $line_no = 0;
    while (my $line = <$fh>) {
        ++$line_no;
        if ($line =~ /^\s*(```|~~~)/) { $fence = !$fence; next; }
        next if $fence;
        while ($line =~ /\]\(([^)]+)\)/g) {
            my $target = $1;
            next if $target =~ m{^(?:https?://|#)};
            $target =~ s/\s+[\x27"].*\z//;
            $target =~ s/#.*\z//;
            $target =~ s/^<|>$//g;
            next if $target eq "";
            my $path = File::Spec->catfile(dirname($file), $target);
            if (!-e $path) {
                print "$file:$line_no:missing link target: $target\n";
                $bad = 1;
            }
        }
    }
    if ($fence) {
        print "$file:unclosed Markdown fence\n";
        $bad = 1;
    }
}
exit($bad ? 1 : 0);
'
```

本轮围栏和本地链接检查退出码为 `0`。两条命令均为只读检查，不创建临时文件，也不触碰
系统显示器路径。
